Este site foi projetado com o objetivo de concluir uma atividade de classe, porém, pode significar muito mais do que isso, afinal, é um projeto até que grandioso.

O que é? AniGame é um site criado para consulta de animes e jogos, tendo também avaliações e comentários sobre cada conteúdo, além de recomendações.

Por que um projeto assim? O projeto foi pensado assim por inicialmente era pensado pelo gosto de uma pessoa só, mas outras pessoas entraram no projeto, mas a ideia continuou a mesma, isso foi pensado pois um site que cobre duas grandes áreas do grande mundo geek, seria uma ótima poupagem de tempo.
